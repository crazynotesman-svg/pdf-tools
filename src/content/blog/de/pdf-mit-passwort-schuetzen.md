Verträge, Angebote, Zeugnisse oder Geschäftsunterlagen: Manche PDFs sind zu wichtig, um sie ungeschützt zu verschicken. Wer sie öffnen soll, muss sie auch öffnen können – aber nicht jeder, der die Datei zufällig in die Hände bekommt, soll den Inhalt sehen. Ein Passwortschutz ist der einfachste Weg, das zu erreichen.

## Öffnungspasswort und Berechtigungspasswort: der Unterschied

PDF-Schutz wird in zwei Ebenen angeboten, und es lohnt sich, sie auseinanderzuhalten:

**Öffnungspasswort:** Ohne das Passwort lässt sich die Datei nicht einmal öffnen. Wer das Passwort kennt, sieht den gesamten Inhalt und kann damit arbeiten.

**Berechtigungspasswort:** Die Datei öffnet sich ohne Passwort, aber bestimmte Aktionen sind eingeschränkt – etwa Drucken, Kopieren oder Bearbeiten.

Für die meisten privaten und geschäftlichen Fälle reicht das Öffnungspasswort: Es verhindert, dass Unbefugte überhaupt an den Inhalt gelangen. Genau das setzt das [PDF Schützen](https://pdf.100ideas.net/de/pdf-schuetzen/) Werkzeug um.

## Passwortschutz lokal im Browser

Der wichtigste Punkt für die Sicherheit Ihres Dokuments: Die Verschlüsselung passiert direkt auf Ihrem Gerät. Die Datei wird **nicht** auf einen Server hochgeladen. Das bedeutet:

- Ihr Dokument verlässt Ihren Computer zu keinem Zeitpunkt.
- Es gibt keine Kopie auf fremden Servern, die nachher gelöscht oder eingesehen werden könnte.
- Sie müssen keinem Dienst vertrauen – der Schutz entsteht lokal, vor Ihren Augen.

Mit einem lokalen Werkzeug gilt: Passwort schützen PDF direkt im Browser – ohne Umwege, ohne Upload.

## So schützen Sie eine PDF in drei Schritten

1. **Datei auswählen:** Ziehen Sie Ihre PDF-Datei per Drag & Drop in das Werkzeug oder wählen Sie sie aus.
2. **Passwort vergeben:** Geben Sie ein Passwort ein, das zum Öffnen der Datei benötigt wird. Wählen Sie eines, das Sie sich merken können – es gibt keine Wiederherstellung.
3. **Herunterladen:** Speichern Sie die geschützte Datei auf Ihrem Gerät. Ab jetzt fragt das PDF beim Öffnen nach dem Passwort.

## Was beim Schutz zu beachten ist

Ein ehrlicher Hinweis: Ein verlorenes Passwort kann nicht wiederhergestellt werden. Die Passwörter werden weder gespeichert noch übertragen – das wäre ein Sicherheitsrisiko. Bewahren Sie das Passwort daher an einem sicheren Ort auf, zum Beispiel in einem Passwortmanager.

Gut zu wissen: Beim Hinzufügen eines Passworts werden die Seiten als hochwertige Bilder in die neue Datei eingebettet. Der visuelle Inhalt bleibt vollständig erhalten – eine Textauswahl ist danach allerdings nicht mehr möglich. Für Dokumente, die nur gelesen und sicher verteilt werden sollen, ist das in der Regel kein Nachteil.

## Wann lohnt sich ein Passwortschutz?

- **Versand vertraulicher Dokumente:** Angebote, Gehaltsnachweise, Vertragsentwürfe.
- **Archivierung sensibler Unterlagen:** Die Datei bleibt auch auf geteilten Geräten geschützt.
- **Befristete Freigaben:** Sie entscheiden, wem Sie das Passwort wann geben – und können es später ändern.

Möchten Sie den Schutz später wieder entfernen? Dafür gibt es das [PDF Entsperren](https://pdf.100ideas.net/de/pdf-entsperren/) Werkzeug – vorausgesetzt, Sie kennen das Passwort. Eine ergänzende Maßnahme für Dokumente, die weitergegeben werden: ein [Wasserzeichen hinzufügen](https://pdf.100ideas.net/de/pdf-wasserzeichen/), etwa mit dem Namen des Empfängers.

## Datenschutz und DSGVO

Gerade für deutsche und europäische Nutzer ist relevant, dass beim lokalen PDF-Schutz keine personenbezogenen Daten übertragen werden. Es entstehen keine Cookies, keine Protokolle über Ihre Dateien, keine Serverzugriffe. Der Schutz ist damit auch eine datenschutzrechtlich einfache Lösung: keine Übermittlung, keine Verarbeitung auf fremden Systemen.

## Häufige Fragen

### Wie setze ich ein Passwort für eine PDF?

Wählen Sie die Datei aus, geben Sie ein Passwort ein und laden Sie die geschützte Datei herunter. Beim nächsten Öffnen fragt das PDF nach dem Passwort.

### Was passiert, wenn ich das Passwort vergesse?

Das Passwort kann nicht wiederhergestellt werden – es wird nirgends gespeichert. Bewahren Sie es sicher auf, etwa in einem Passwortmanager.

### Wird meine Datei hochgeladen?

Nein. Die Verschlüsselung erfolgt vollständig in Ihrem Browser. Ihre Datei verlässt niemals Ihr Gerät.

### Ist das Werkzeug kostenlos?

Ja. Das Schützen von PDFs ist dauerhaft kostenlos und ohne Registrierung.

### Kann ich das Passwort später entfernen?

Ja, mit dem Entsperren-Werkzeug – sofern Sie das Passwort kennen. Sie können auch jederzeit ein neues Passwort setzen.

### Funktioniert es auf dem Handy?

Ja. Da alles im Browser läuft, funktioniert der Schutz auf Desktop und Mobilgeräten gleichermaßen.
