Viele alltägliche Dokumente liegen als separate PDFs vor: Verträge, Rechnungen
oder Bewerbungsunterlagen. Statt sie einzeln zu versenden, ist es oft sinnvoller,
sie zu einer einzigen Datei zusammenzuführen.

## Warum PDFs zusammenführen?

- **Ordnung:** Alle Unterlagen zu einem Vorgang landen in einer Datei.
- **Einfacheres Teilen:** Eine E-Mail, ein Anhang, weniger Fehlerquelle.
- **Datenschutz:** Mit lokalen Werkzeugen verlässt die Datei nie Ihren Browser.

## So funktioniert es

1. Wählen Sie die gewünschten PDF-Dateien aus.
2. Legen Sie die Reihenfolge der Seiten fest.
3. Führen Sie die Dateien zusammen und laden Sie das Ergebnis herunter.

Unser Werkzeug erledigt das vollständig in Ihrem Browser – ohne Upload auf einen
Server. So bleiben sensible Dokumente privat.
