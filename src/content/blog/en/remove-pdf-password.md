You received or created a PDF that asks for a password when opened – and you know the password. Maybe the prompt gets in the way when you want to print or edit the document, or you took over the file from a colleague and want to place it in a shared folder. In that case, the password protection can be cleanly removed.

## What this tool can do – and what it won't

First, an important point about security: password protection can only be removed with the known password. There is no backdoor, no trick, and no "master key". If you don't know the password, this tool cannot open or unlock the file – and that's intentional. A tool that bypasses other people's passwords would be a tool for cracking protection. We deliberately don't offer that.

In such a case, contact the person who sent the file or the organization that set the password.

## Two cases, two paths

When unlocking, it depends on how the file is protected:

**Permission restrictions only:** Some PDFs open fine, but actions like printing or copying are restricted. Here it's enough to re-save the file – the content stays fully intact and the restrictions are dropped.

**Open password:** The file asks for a password when opened. After entering it, the file is rebuilt with its content. The visual content is preserved; depending on the original protection, text selection may no longer be possible.

Both paths run entirely in your browser with the [Unlock PDF](https://pdf.100ideas.net/en/pdf-unlock/) tool.

## How to remove the password in three steps

1. **Select a file:** Drag and drop your protected PDF into the tool or pick it from the file dialog.
2. **Enter the password:** Type the file's password.
3. **Download:** Save the unlocked file to your device.

The password is only used for decryption in your browser – it is neither stored nor transmitted.

## Privacy: your file stays with you

As with all our tools: the file is not uploaded. Processing runs exclusively on your device. No server copies, no logs, no cookies. That matters especially when you're unlocking documents with personal or business data.

## When is removing the password worth it?

- **Shared use:** Several people should open the file without a password prompt.
- **Further processing:** You want to print, edit, or merge the document with other PDFs.
- **Archiving:** For your own storage, the password prompt is often unnecessary – after all, you created the file.

Keep in mind: an unlocked file can be opened by anyone who receives it. Remove the protection only when that's acceptable for your purpose. If the file should be protected again, use the [Protect PDF](https://pdf.100ideas.net/en/pdf-protect/) tool to set a new password. A [watermark](https://pdf.100ideas.net/en/pdf-watermark/) tool is also available to label documents you share.

## Frequently asked questions

### Do I need the password to unlock a PDF?

Yes. Without the known password, the protection cannot be removed – there is no workaround.

### I forgot the password. What now?

Unfortunately, the file cannot be unlocked then. Contact the sender or the organization that set the password.

### Is my file uploaded?

No. Processing happens exclusively in your browser. Your file never leaves your device.

### Does unlocking change my file's content?

For files with permission restrictions only, the content stays fully intact. For files with an open password, the content is rebuilt after the password is entered – the visual content stays, but text selection may be lost depending on the file.

### Is the tool free?

Yes. Unlocking PDFs is free forever and requires no registration.

### Does it work on mobile?

Yes. Because processing runs in the browser, it works on desktop and mobile alike.

## Wrap-up

If you know a PDF's password, you can remove the protection in a few clicks – locally, safely, and free. The limit is intentional: without the password there is no way in. Unlock with the [Unlock PDF](https://pdf.100ideas.net/en/pdf-unlock/) tool, and if needed, protect the file again afterwards with the [Protect PDF](https://pdf.100ideas.net/en/pdf-protect/) tool.
